# Product context

Job seekers repeatedly encounter duplicated and stale listings across fragmented platforms. Existing aggregators primarily optimize discovery; this project optimizes longitudinal search state.

The user should be able to ask: “What genuinely new or changed opportunities match me since my last check?”

The system should also answer which sources add unique value and how advertised demand changes over time.
