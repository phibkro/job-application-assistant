# Provenance: `apps/index-web`

The index client (WS-0025@2) is built from Foldkit's official examples at the pinned release **`foldkit@0.170.0`** (commit `a471adb`, the git-ignored checkout at `repos/foldkit/` fetched by `scripts/setup.sh`). No example file was copied verbatim. Each module below adapts the named example's structure to this app's domain, following the repository's formatting (oxfmt) and lint rules. The upstream examples are MIT-licensed (`repos/foldkit/LICENSE`).
