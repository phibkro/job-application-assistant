## Network deployments

The AGPL adds a network-source requirement for modified versions used through a computer network. Before operating a modified public deployment, provide users a clear way to obtain the corresponding source for the version actually running. A visible **Source** link in the web interface is the preferred project convention.

The repository does not yet prescribe one hosting provider for corresponding source. The production deployment gate must record the source URL and verify that it identifies the deployed revision.
